# KLEOPATRA — демо главной страницы

Студия красоты и лазерной эпиляции «Клеопатра», Казань, пр. Ямашева, 90.
Концепция «Золотая стрелка»: одна золотая линия идёт через всю страницу — стрелка под вордмарком → луч лазера, «очищающий» фото → ось времени «Одним днём» → обводка арки → картуш вокруг адреса.

## Запуск

- Двойной клик по `index.html` — работает с `file://` (проверено, без ошибок в консоли).
- Или локальный сервер: `node tools/serve.mjs 8720` → http://localhost:8720/
- Деплой — любая статика (Vercel, GitHub Pages): корень = эта папка, сборки нет.
  Для клиентов из России лучше GitHub Pages: `*.vercel.app` у части провайдеров не открывается.
- Опубликовано: https://purich755.github.io/Kleopatra/ (репозиторий purich755/Kleopatra, workflow `.github/workflows/pages.yml` выкладывает только `index.html`, `css`, `js`, `assets` при каждом пуше в `main`).
- `<meta name="robots" content="noindex">` убрать, когда сайт станет боевым.

Стек: HTML + CSS + vanilla JS, GSAP 3.13 + ScrollTrigger и Lenis 1.3 с jsDelivr, шрифты Google Fonts (Forum, Cormorant Infant, Manrope, IBM Plex Mono). Весь контент — в `js/data.js`.

## Что подтвердить у клиента

1. **Точный график.** На сайте только «Открываемся в 8:00 · по предварительной записи». Яндекс пишет «ежедневно 8:00–20:00», в брифе упоминалось 22:00 — нужно одно значение.
2. **Актуальность прайса и акций.** Прайс на Яндексе помечен как давно не обновлявшийся: −30% на первое посещение, комплексы лазера, абонементы 5/8/10 мес.
3. **Марка лазерного аппарата** — на сайте только «премиум-класса».
4. **Состав мастеров и согласие** на имена и фото; можно ли поставить портреты в арки вместо монограмм.
5. **Фото из отзывов гостей** (работы маникюра, кератин) — можно ли использовать.
6. **Оплата картой** — по Яндексу только наличные и перевод.
7. Массажная со свечами и съёмка команды похожи на фотостудию — уточнить, это интерьер студии или выездная съёмка.
8. Хиджама и пирсинг — оставлять ли в открытом прайсе.
9. Какой Instagram указывать (их два) и нужна ли ссылка на taplink.
10. Виджет Яндекс Карт: нижняя рекламная полоса срезана рамкой, но рекламу внутри виджета контролировать нельзя — при желании заменить на статичную карту.
